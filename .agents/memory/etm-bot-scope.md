---
name: ETM bot scope
description: Product scope for ETM's Discord achievement tracker and its OWO relationship.
---

ETM is a Discord bot users can add to their servers. It tracks milestones created by ETM from actions users manually report doing with OWO.

**Why:** The user clarified they want a server-installable bot and confirmed the manual achievement-tracker approach.

**How to apply:** Build Discord slash commands for self-reported progress. Do not run OWO commands, control OWO, or claim achievements on users' behalf.
